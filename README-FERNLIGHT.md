# fernlight

Personal proxy browser built on Scramjet (Mercury Workshop, AGPL-3.0).

## Run on your computer
1. Install Node.js 18+ from nodejs.org
2. Open a terminal in this folder and run:
   npm install
   npm start
3. Open http://localhost:8080

## Background photo
Put any image in `public/bg.jpg` and it becomes the background.

## Host it online (free)
Push this folder to GitHub, then on Render.com: New > Web Service > pick the repo.
Build command: npm install   Start command: npm start
(Netlify won't work - it needs a server that stays running.)
